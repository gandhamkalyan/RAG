Where does the text come from?



Before chunking, embeddings, or retrieval, we must first extract text from documents. This is the job of a Text Loader (Document Loader).



**Intuition**



Imagine you have a PDF: Employee\_Handbook.pdf

The LLM cannot directly understand: .pdf

Similarly, it cannot directly understand: .docx ,.xlsx ,.html ,.csv. These are file formats.



Before processing them, we need to:

Open File

&#x20;    ↓

Read Content

&#x20;    ↓

Extract Text



This process is called Loading.

The component that does this is called: Text Loader (Document Loader)



**Why Do We Need a Loader?**



Suppose you have a PDF.



Internally PDF looks something like:

Page Layout

Fonts

Images

Coordinates

Metadata

Text



The embedding model only needs: Actual Text

The loader extracts only the useful content.

\-----------------------------

**Different Types of Loaders**



Different file types require different loaders.



| File Type  | Loader            |

| ---------- | ----------------- |

| TXT        | Text Loader       |

| PDF        | PDF Loader        |

| DOCX       | Word Loader       |

| CSV        | CSV Loader        |

| HTML       | Web Loader        |

| SQL Table  | Database Loader   |

| SharePoint | SharePoint Loader |

**Context Window**



**Intuition First**



Imagine you're taking an exam.

You have: 1000 pages of notes



But the examiner says: "You can only bring 10 pages into the exam hall." Those 10 pages are your context window.

Anything outside those 10 pages cannot be seen by you during the exam.



**LLM Version**



An LLM works similarly. When you ask a question, the model can only "see" a limited amount of text at one time. That limit is called:

**Context Window =** Maximum amount of text (tokens) an LLM can process in a single request.



What Goes Into Context Window?



Many beginners think only the question goes in.

Actually the context window contains:



System Prompt

\+

Chat History

\+

Retrieved Chunks (RAG)

\+

User Question



Everything consumes tokens.
