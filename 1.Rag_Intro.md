**Chapter 1: What Problem Does RAG Solve?**



Before understanding RAG, let's understand the problem.



Imagine you ask ChatGPT: "What is the latest Fabric capacity feature released last week?"



**A normal LLM has two problems:**



**Problem 1: Knowledge Cutoff**

The model was trained earlier.

It doesn't know last week's feature.



**Problem 2: Company-Specific Data**

Suppose you ask:"How many sales orders are present in my SAP table?"

The model never saw your SAP database during training.

Therefore it cannot answer

\--------------------------------------

**Traditional LLM**



Think of a student.



Before exam:

Reads books

Learns information

Stores knowledge in brain



During exam:

Cannot open books

Answers from memory



LLM works exactly like this.



Question

&#x20;   ↓

LLM Memory

&#x20;   ↓

Answer



The model only uses what it learned during training.

\------------------------------------------

**RAG Idea**



RAG = Retrieval Augmented Generation



Break into 3 words.

Retrieval : Find relevant information.



Augmented : Add that information to prompt.



Generation :Generate answer using LLM.



**Instead of asking LLM directly:**

Question

&#x20;  ↓

LLM

&#x20;  ↓

Answer

\-------------------

**We do:**



Question

&#x20;  ↓

Retrieve Documents

&#x20;  ↓

Add Documents to Prompt

&#x20;  ↓

LLM

&#x20;  ↓

Answer



This is RAG.

\--------------------------------

Real Example



Suppose you uploaded a PDF: Fabric Capacity Guide.pdf

Question: What is CU consumption?



RAG process:



**Step 1**  : Search PDF.



Find:

Capacity Units measure compute resources

used by Fabric workloads.



**Step 2** : Pass to LLM.



Context:

Capacity Units measure compute resources

used by Fabric workloads.



Question:

What is CU consumption?



**Step 3** : LLM answers.



CU consumption refers to the amount of

Fabric compute resources used by workloads.



Notice:The answer came from PDF.

Not from model memory.

Imagine a New Employee



Suppose a company hires a new employee named John.

John has general knowledge. Now the company wants him to answer questions about company policies.

There are 3 ways to make John better



**Method 1: Prompt Engineering**



You simply give better instructions.

Example: 

Instead of saying: Answer customer questions.



You say: You are a customer support specialist.

Follow these rules:

1\. Be polite.

2\. Give short answers.

3\. Use company tone.

4\. If uncertain, say I don't know.



John's knowledge didn't change.

Only instructions changed.



This is Prompt Engineering.



**Purpose of Prompt Engineering**

Prompt engineering changes:

Behavior

Tone

Format

Reasoning style

Output structure

It does NOT add new knowledge.

\-----------------------------

**Method 2: Fine-Tuning**



Now suppose John works at your company for 6 months.



He studies:

Company policies

Internal procedures

Customer interactions



Eventually he learns them permanently.

His brain changes. This is Fine-Tuning.



LLM Version



**During fine-tuning:**



**Base Model**

&#x20;     **+**

**Training Data**

&#x20;     **↓**

**Model Weights Updated**

&#x20;     **↓**

**New Model**



The model itself changes.



**What Are Weights?**



LLM knowledge is stored in parameters.



Think: Brain Memory for humans.



or



Weights for neural networks.



Mathematically: A neural network is:



y=f(Wx+b)



Where:

x = input

W = weights

b = bias

y = output



Fine-tuning changes: W the weights.



**Purpose of Fine-Tuning**



Fine-tuning teaches:

Domain knowledge

Specialized vocabulary

Writing style

Repeated tasks

Company-specific behavior

\---------------------------------------

**Key Difference**



Prompt Engineering: Changes Instructions



Fine-Tuning: Changes Model



RAG: Changes Context



This is the easiest way to remember.





**Why Fine-Tuning Is Bad for Dynamic Data**



Suppose customer count today: 1000

Tomorrow: 1200

Fine-tuned model still remembers: 1000



because knowledge is baked into weights.



RAG retrieves: 1200 from latest source. This is why RAG dominates enterprise AI.
